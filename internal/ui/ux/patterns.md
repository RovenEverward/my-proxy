# UX 交互模式

模式以用户任务组织。业务数据由控制面判定。以下表格区分已实现行为与迁移边界。

## 导航与读取

| 条件 | 行为与结果 | 实现与验收 |
| --- | --- | --- |
| 切换页面 | 立即切换目标标题、面包屑与加载框架。旧响应不得覆盖目标页 | [query.ts](../frontend/runtime/query.ts)；[导航加载测试](../e2e/nav-loading.spec.mjs) |
| 返回已访问页面 | 先显示成功缓存，再读取远端。失败时保留已显示的数据 | [数据复用测试](../e2e/data-reuse.spec.mjs) |
| 打开用户详情 | 保留用户列表状态、筛选和滚动。关闭后继续原任务 | [用户详情](../frontend/pages/users/detail.tsx)；[数据复用测试](../e2e/data-reuse.spec.mjs) |
| 同页刷新 | 保留滚动位置。手动刷新失败时提供重试 | [刷新测试](../e2e/refresh.spec.mjs) |
| 后台读取失败 | 保留成功数据，提示读取失败。禁止用错误空态替换已有内容 | [导航加载测试](../e2e/nav-loading.spec.mjs) |

导航使用有效链接。页面内操作使用按钮或原生控件。图标按钮提供无障碍名称和悬停说明。状态同时使用文字或形状，不能只靠颜色。

## 表单与保存

| 条件 | 行为与结果 | 实现与验收 |
| --- | --- | --- |
| 服务端拒收 | 保留输入，显示具体原因，允许修正或重试 | [用户测试](../e2e/users.spec.mjs) |
| 订阅草稿有改动 | 使用统一保存条。离页与切换控制面经过同一草稿确认 | [订阅页](../frontend/pages/sub/SubscriptionPage.tsx)；[订阅测试](../e2e/sub.spec.mjs) |
| 保存设置 | 先读取最新设置，只覆盖本次改动的字段 | [订阅测试](../e2e/sub.spec.mjs) |
| 续期成功但清零失败 | 只重试清零，不重复顺延到期日 | [过期用户测试](../e2e/expired-users.spec.mjs) |
| 批量删除部分失败 | 保留结果，仅重试失败名单 | [过期用户测试](../e2e/expired-users.spec.mjs) |

加载、成功和不可用必须对应真实状态。控件值改变不等于保存成功。异步操作使用 `Button` 的 `loading` 态或等价忙态，立即显示。需要业务锁的写操作仍由调用方持有锁。

字段使用可见标签。错误说明关联具体字段。新组件使用 `aria-invalid` 和 `aria-describedby`。不得只用输入框占位文本充当标签。

## 浮层与菜单

异步详情用 `usePageData` 加载、经 `openDrawer` 展示。先显示目标框架，再补充内容。关闭或切换对象后丢弃旧结果。普通抽屉复用 `useApp().openDrawer`，确认操作复用 `useApp().confirmBox`。

危险确认说明对象、范围和后果。需要逐字核对时使用 `Confirmation.typed`。提交期间不能取消的流程用 `setModalLocked` 锁定。失败留在原确认框并提供恢复路径。

模态组件须提供可访问名称、进入焦点、Tab 范围、Escape 行为和关闭后的焦点恢复。Radix 对话框承担焦点约束与 Escape；页面装配仍须按页验收。现有订阅离页确认已有完整案例，见[订阅测试](../e2e/sub.spec.mjs)。

行菜单复用 `ActionMenu`，保留单开、外点关闭、Escape 关闭和视口避让。原生 select 继续承担键盘选择和值的所有权；自定义选择控件使用 [native-select.tsx](../frontend/components/native-select.tsx)。

## 主题、内容与动效

根主题控制当前页面与它打开的浮层。切换到其他页面时，由路由切换样式绑定。组件不自行存储主题副本。

长名称允许省略，但必须保留对象识别与必要动作。告警详情入口不与辅助说明共同截断。窄屏保留返回路径和底部导航。

动效用于按压、状态切换与首次进入。状态稳定后停止无意义运动。减少运动时仍显示状态变化和真实结果。

## 现有边界

以下是已确认的迁移事项，不代表已经全部实现：

- Radix 对话框与菜单提供焦点约束和菜单项语义；真实页面验收覆盖名称、背景隔离、键盘范围和关闭后的焦点。
- 行菜单尚未在目录外统一验收方向键行为。
- 订阅以外的页面尚无统一的草稿离开保护。
- 读取层丢弃过期响应，尚无统一取消或超时控制器。

本轮建立规范与入口，不扩展这些业务流程。以后改动相关组件时，按本页契约补齐，并通过真实入口验证。
