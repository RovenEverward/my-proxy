# 控制面与节点

## 两种角色

MPX 把一套代理服务分成两种机器：

- **节点**：真正转发用户流量的服务器，上面跑 xray（Hysteria2 / TUIC 用 sing-box）。
- **控制面**：记账的服务器。它保存节点、入站、用户和设置，把配置推给节点，并向客户端发订阅。

你在自己电脑上用 MPX 桌面程序操作控制面。用户的客户端只和控制面打一次交道：拉订阅。之后流量直接连节点。

```text
 MPX 桌面程序 ─管理─▶ 控制面 ◀──订阅── 用户客户端
                       │ SSH + 核心统计接口      │
                       ▼                         │ 代理流量
                  节点 A、节点 B ◀───────────────┘
```

## 为什么控制面不在流量路径上

控制面停了，已经拿到订阅的用户照常上网，只是暂时不能拉新订阅、不同步新用户、不记流量。代价是控制面无法实时拦截流量：停用和超额要等下一轮同步（默认 30 秒）才落到节点。

## 两种改动，两种生效方式

| 改动 | 例子 | 怎么生效 | 对在线用户 |
| :--- | :--- | :--- | :--- |
| 名单改动 | 加人、删人、停用、到期、超额 | 控制面每轮自动同步，经 xray gRPC 接口热更新 | 不断线 |
| 结构改动 | 新增入站、改端口、换证书 | 只有在节点详情里点 **应用到节点** 才生效 | 该节点所有连接断一次 |

下发不会自动发生，所以你可以决定何时让节点重启。Hysteria2 / TUIC 节点是例外：它们的名单变化也会重启该节点全部 QUIC 连接。

## 入站和入口

- **入站**是节点上监听的一个端口和协议，例如 443 端口上的 VLESS + REALITY。
- **对外入口**（host）是客户端连这个入站时用的地址。同一个入站可以有多个入口，例如一个直连 IP、一个经 CDN 的域名。

订阅里的每条线路对应一个入口。

## 默认入站：不需要域名和证书

首次安装向导和添加节点向导默认建的入站都是 VLESS + TCP + REALITY，监听 443 端口。REALITY 借用一个公开网站（默认 `www.cloudflare.com`）的 TLS 握手，外面看起来像在访问那个网站，所以不需要你自己的域名和证书。

要用 Hysteria2 或 TUIC，在节点上另加入站，并在节点详情里用 **安装核心** 装上 sing-box。

## 一条地址，两种凭据

每个用户有两套互相独立的凭据：

- **协议凭据**：节点认它，决定能不能连上。
- **订阅 token**：在订阅地址里，决定能不能拉到配置。

所以订阅地址泄露时，**吊销订阅** 只换 token，已连上的设备不受影响；要真正踢掉一个人，停用或删除他。
