# 添加节点

把一台新的 VPS 加成代理节点。完成后，所有能用这台节点的用户在下次更新订阅时会看到新线路。

前提：MPX 已接入控制面；新 VPS 运行 Linux，你知道它的 IP 和 root 密码。

## 用向导添加

1. 在左侧点 **节点**，再点右上角 **添加节点**。
2. **连接**：填 **服务器地址**（例如 `203.0.113.30`）和 **SSH 密码**。SSH 端口和用户不是 `22` 和 `root` 时一起改。点 **下一步**。
3. **入站**：保持默认（VLESS + REALITY，端口 443），点 **开始安装**。窗口逐项显示进度。
4. **完成**：看到「🇸🇬 新加坡 A 已就绪」这样的提示后，点 **查看节点**。

<Shot name="node-wizard" cap="添加节点：连接" size="dialog" />

不用给节点起名：显示名（如 🇸🇬 新加坡 A）按这台机器的 IP 自动识别，订阅里客户端看到的也是它；识别得不对，之后在节点页 **编辑** 里改地区和城市。

SSH 密码只用来把控制面的公钥装到这台机器上一次，用完即丢，不保存。这台机器已经装了控制面的公钥时，点表单上方的 **已能免密 SSH，直接登记**。

## 验证

在 **节点** 列表里，新节点的状态变成「运行中」。点它打开详情，可以看到核心版本、节点配置是否已是最新，以及它上面的 **连接方式**。

<Shot name="node-detail" cap="节点详情" />

详情页还有刷新状态、暂停分配、体检等维护操作，说明见[界面参考](/reference/interface#节点详情里的操作)。

::: details 改了连接方式或端口之后要点「应用到节点」
加人、删人、停用这类改动会自动同步，不断线。新增入站、改端口、换证书这类改动不会自动生效：在节点详情里点 **应用到节点** 才生效，并且核心会重启，该节点上的所有连接会断开一次。所以你可以自己挑时间下发。原因见[控制面与节点](/concepts/architecture)。
:::

## 端口被占用

默认的 443 已经被别的程序（比如 nginx）占着时，向导会自动换一个空闲端口（2087、2053 等），进度里写明换成了哪个。你在 **高级** 里自己填的端口被占时，向导会停在「建入站和入口」这一步，写清是哪个程序占的：

- 点 **改端口**，换一个端口后再点 **开始安装**，从这一步接着来，节点不用重建；
- 或者先在 VPS 上停掉占用它的程序，再点 **重试这一步**。

## 出了问题

| 症状 | 处理 |
| :--- | :--- |
| 连接这一步失败 | 窗口按原因提示：连接被拒或超时，核对 IP、SSH 端口，确认 VPS 防火墙（安全组）放行了 SSH 端口；密码不对，核对 root 密码，或确认这台机器允许密码登录 |
| 「建入站和入口」报端口已被占用 | 见上面的[端口被占用](#端口被占用) |
| 状态是「连不上」 | 点 **刷新状态** 看具体报错；也可以跑一次[体检](/guides/troubleshoot) |
| 订阅里没有这台节点 | 确认用户的套餐包含这台节点，见[用套餐分配节点](/guides/plans) |
