# 添加节点

把一台新的 VPS 加成代理节点。完成后，所有能用这台节点的用户在下次更新订阅时会看到新线路。

前提：MPX 已接入控制面；新 VPS 运行 Linux，你知道它的 IP 和 root 密码。

## 用向导添加

1. 在左侧点 **节点**，再点右上角 **添加节点**。
2. **连接**：填 **服务器地址**（例如 `203.0.113.30`）、**节点名**（例如 `sg-1`，只用字母、数字和 `-`）和 **SSH 密码**。SSH 端口和用户不是 `22` 和 `root` 时一起改。点 **下一步**。
3. **入站**：保持默认（VLESS + REALITY，端口 443），点 **下一步**。
4. **安装**：点 **开始安装**。窗口逐项显示进度。
5. **完成**：看到「sg-1 已就绪」后，点 **查看节点**。

<Shot name="node-wizard" cap="添加节点：连接" />

SSH 密码只用来把控制面的公钥装到这台机器上一次，用完即丢，不保存。这台机器已经装了控制面的公钥时，点表单上方的 **已能免密 SSH，直接登记**。

## 验证

在 **节点** 列表里，新节点的状态变成「运行中」。点它打开详情，可以看到核心版本、配置是否已下发、证书有效期和它上面的入站。

## 改了入站或端口之后

加人、删人、停用这类改动会自动同步，不断线。新增入站、改端口、换证书这类改动不会自动生效：在节点详情里点 **下发配置** 才生效，并且核心会重启，该节点上的所有连接会断开一次。所以你可以自己挑时间下发。原因见[控制面与节点](/concepts/architecture)。

## 其他维护操作

节点详情里还有：

| 操作 | 作用 |
| :--- | :--- |
| **现场检查** | 立刻登录节点查看运行状态，不等下一轮巡检 |
| **排水** | 新订阅不再包含这台节点，已连上的用户在下次刷新订阅时换到别的节点；点 **结束排水** 恢复 |
| **体检** | 在节点上检查健康状况和出口能力，最长要十几分钟 |
| **安装核心** | 在节点上安装 xray 或 sing-box，下发当前配置并启动 |
| **在线用户** | 查看现在连着这台节点的用户 |
| **配置预览** | 查看即将下发到节点的配置 |
| **删除节点** | 删除节点和它的入站，订阅里不再有它；机器上的核心不清理。按提示输入节点名确认 |

## 出了问题

| 症状 | 处理 |
| :--- | :--- |
| 连接这一步报 SSH 错误 | 核对 IP、端口和 root 密码；确认 VPS 防火墙放行了 SSH 端口 |
| 状态是「连不上」 | 点 **现场检查** 看具体报错；也可以跑一次[自检](/guides/troubleshoot) |
| 订阅里没有这台节点 | 确认用户的套餐包含这台节点，见[用套餐分配节点](/guides/plans) |
