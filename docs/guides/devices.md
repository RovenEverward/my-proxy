# 在多台设备上管理控制面

`mpx init` 结束时，跑它的那台电脑已经接入了控制面。本页讲怎样把别的设备也接进来、怎样踢掉一台设备、忘了设备密码怎么办。全程不需要登录 VPS。

## 接入一台新设备

在新设备上装好 `mpx`（见[快速开始](/tutorial/quickstart)第 1 步），然后运行 `mpx init` 最后打印的那一行：

```bash
mpx connect 203.0.113.10:8080 --fp SHA256:DU4SswBA8LrUy6O0MfhRRxLJZ2p8GPREpV2Zfxtj9Wg
```

输入设备密码后，这台设备拿到一枚自己的 token，和控制面地址、证书指纹一起存进配置文件：

```text
设备密码:
已接入 https://203.0.113.10:8080:本设备「office-pc」(设备 2),存在配置档 default。
```

设备名默认是主机名，用 `--name` 改。

::: tip 手边没有那一行
不带 `--fp` 也能接入：命令会先显示控制面的证书指纹，你输入 `yes` 确认后才继续。拿它和已接入设备上 `mpx status` 里的「证书指纹」对一下。指纹对不上时不要确认，可能有人冒充了控制面。
:::

## 看有哪些设备，吊销一台

```bash
mpx device list
```

```text
   ID  名称       接入时间           最近使用  最近 IP
*  1   macbook    2026-10-15 07:58  1 秒前   198.51.100.7
   2   office-pc  2026-10-15 08:10  3 天前   198.51.100.20
```

`*` 是你正在用的这台。丢了或不再用的设备，按 ID 或名称吊销，它的 token 立刻失效：

```bash
mpx device revoke office-pc
```

## 改设备密码

在任何一台已接入的设备上：

```bash
mpx device password
```

改密码不影响已经接入的设备。怀疑密码泄露、想把所有设备一起踢掉时加 `--revoke-all`，之后每台设备都要重新 `mpx connect`。`mpx device password --disable` 关闭设备密码接入。

## 出了问题

| 症状 | 原因 | 处理 |
| :--- | :--- | :--- |
| 「证书指纹不符」 | 控制面重装过、换了证书，或者有人在中间冒充 | 确认是前者后，重新运行 `mpx connect` |
| 「设备密码不对」 | 输错了 | 在已接入的设备上 `mpx device password` 重设 |
| 「接入已锁定」 | 设备密码连续输错 20 次 | 等 15 分钟；已接入的设备不受影响 |
| 「token 不正确或这台设备已被吊销」 | 这台设备被吊销了 | 重新 `mpx connect` |
| 命令行提示「管理接口正在走明文 HTTP」 | 配置档还是老版本的 `http://` 地址 | 运行 `mpx connect --upgrade` |

管理接口走 HTTPS，订阅仍是同一端口上的 HTTP，因为代理客户端一般不认控制面的自签证书。
