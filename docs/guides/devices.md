# 在多台设备上管理

首次安装结束时，你用的那台电脑已经接入了控制面。本页讲怎样把另一台电脑也接进来、怎样踢掉一台设备、怎样改设备密码。全程不需要登录 VPS。

## 接入一台新设备

你需要两样东西：控制面的地址（例如 `203.0.113.10:8080`）和首次安装时设的设备密码。

1. 在新电脑上安装 MPX，见[快速开始](/tutorial/quickstart)第 1 步。
2. 打开 MPX，在欢迎页点 **接入已有控制面**。
3. **控制面地址** 填 `203.0.113.10:8080`，**设备名** 留空时用这台电脑的主机名。点 **取指纹**。
4. 窗口显示控制面的**证书指纹**。它应当和首次安装 **完成** 页显示的证书指纹一致。一致时，勾上 **指纹核对无误，是我的控制面**，输入 **设备密码**，点 **接入**。

<Shot name="setup-connect" cap="接入已有控制面" />

接入后，这台设备拿到自己的一枚凭据，直接进入管理界面。

::: warning 指纹对不上时不要接入
指纹不一致，说明控制面重装过、换了证书，或者有人在中间冒充控制面。先确认是哪种情况。
:::

## 看有哪些设备，吊销一台

在左侧点 **设置**，再点 **设备** 标签页：

<Shot name="settings-devices" cap="设置 · 设备" />

标着 **这台** 的是你正在用的设备。丢了或不再用的设备，点它右侧的 **吊销**。它的凭据立刻失效，要再用得重新接入。

界面不允许吊销「这台」，免得把自己踢下线。

## 改设备密码

在同一页的 **设备密码** 一节：

1. 填 **新密码**（至少 12 个字符）和 **再输一次**。
2. 点 **保存设备密码**。

改密码不影响已经接入的设备。怀疑密码泄露、想把所有设备一起踢掉时，保存前勾上 **同时吊销所有已接入设备**；之后每台设备（包括这台）都要重新接入。

不想再让新设备接入时，点 **关闭设备密码接入**。已接入的设备不受影响；要再打开，在这里设一个新密码。

## 出了问题

| 症状 | 原因 | 处理 |
| :--- | :--- | :--- |
| 「证书指纹不符」 | 控制面重装过、换了证书，或者有人在中间冒充 | 确认是前者后，重新接入 |
| 「设备密码不对」 | 输错了 | 在已接入的设备上改设备密码 |
| 「接入已锁定」 | 设备密码连续输错 20 次 | 等 15 分钟；已接入的设备不受影响 |
| 打开 MPX 提示凭据无效 | 这台设备被吊销了 | 在欢迎页重新 **接入已有控制面** |
