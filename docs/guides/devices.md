# 在多台设备上管理

首次安装结束时，你用的那台电脑已经接入了控制面。本页讲怎样把另一台电脑也接进来、忘了设备密码怎么办、怎样踢掉一台设备。全程不需要登录 VPS。

## 接入一台新设备

你需要两样东西：控制面的地址（例如 `203.0.113.10:8080`）和首次安装时设的设备密码。

1. 在新电脑上安装 MPX，见[快速开始](/tutorial/quickstart)第 1 步。
2. 打开 MPX，在欢迎页点 **接入已有控制面**。
3. 填 **控制面地址**，点 **取指纹**；看一眼显示的证书指纹和首次安装 **完成** 页上的一样，勾上 **指纹核对无误**，输入 **设备密码**，点 **接入**。

<Shot name="setup-connect" cap="接入已有控制面" size="dialog" />

接入后直接进入管理界面。**设备名** 可以不填，默认用这台电脑的主机名。

::: details 为什么要核对证书指纹？
控制面用自己生成的证书加密管理接口，MPX 认的是这枚证书的指纹。指纹对不上，说明控制面重装过、换了证书，或者有人在中间冒充控制面——先确认是哪种情况再接入。

已接入设备上的指纹在 **设置 → 通用** 顶部的 **当前控制面** 里，可以复制下来对照。
:::

## 忘了设备密码

- **还有一台已经接入的设备：** 在它上面打开 **设置 → 设备**，在 **设备密码** 一节设一个新密码，保存。已接入的设备不受影响，新设备用新密码接入。
- **一台已接入的设备都没有：** 只能登 VPS 重设，见下面的折叠块。

::: details 一台已接入的设备都没有
这是整个 MPX 里唯一需要登 VPS 的情况。SSH 登录 VPS，运行下面这条命令，按提示输入两次新密码：

```sh
sudo sh -c 'MPX_TOKEN="$(sed -n "s/^MPX_TOKEN=//p" /etc/mpx/env)" mpx --server http://127.0.0.1:8080 device password'
```

控制面监听的端口不是 8080 时，把命令里的 `8080` 换成实际端口。
:::

### 输错太多次被锁定

设备密码连续输错太多次，接入会锁定 15 分钟。窗口会直接告诉你锁到几点（本机时间）、还要等多久；已经接入的设备不受影响，照常使用。等时间到了再试，或者按上面的办法重设密码。

## 看有哪些设备，吊销一台

在左侧点 **设置**，再点 **设备** 标签页：

<Shot name="settings-devices" cap="设置 · 设备" />

标着 **这台** 的是你正在用的设备。丢了或不再用的设备，点它右侧的 **吊销**。它的凭据立刻失效，要再用得重新接入。

界面不允许吊销「这台」，免得把自己踢下线。

## 改设备密码

在同一页的 **设备密码** 一节：

1. 填 **新密码**（至少 12 个字符）和 **再输一次**。
2. 点 **保存设备密码**。

改密码不影响已经接入的设备。怀疑密码泄露、想把所有设备一起踢掉时，保存前勾上 **同时吊销所有已接入设备**；之后每台设备（包括这台）都要重新接入。

不想再让新设备接入时，点 **关闭设备密码接入**。已接入的设备不受影响；要再打开，在这里设一个新密码。

## 出了问题

| 症状 | 原因 | 处理 |
| :--- | :--- | :--- |
| 「证书指纹不符」 | 控制面重装过、换了证书，或者有人在中间冒充 | 确认是前者后，重新接入 |
| 「设备密码不对」 | 输错了，或忘了 | 见上面的[忘了设备密码](#忘了设备密码) |
| 「接入已锁定」 | 设备密码连续输错太多次 | 窗口会显示解锁时间，到点再试；已接入的设备不受影响 |
| 打开 MPX 提示凭据无效 | 这台设备被吊销了 | 在欢迎页重新 **接入已有控制面** |

## 接入另一套控制面并切换

你管理不止一套控制面时（例如一套自用、一套给家人），可以都接进同一个 MPX：

1. 点左上角的配置档卡片，在弹出的列表里点 **添加控制面…**。
2. 和接入新设备一样填 **控制面地址**、点 **取指纹**、核对指纹并勾上确认。
3. 填 **配置档名**（字母、数字、`-`、`_`，最多 32 个字符，不能和已有的重名），输入那套控制面的 **设备密码**，点 **接入**。

接入成功后窗口直接切到新控制面。以后点配置档卡片，在列表里点一项就能来回切换；每项后面显示证书指纹的前 16 位，方便分辨。
