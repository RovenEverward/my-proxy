# 备份控制面

把控制面的全部数据（用户、节点、套餐、规则、设置）下载成一个文件，存到你的电脑上。

下载备份在窗口里点一下就行；**恢复要用命令行**，界面里没有恢复按钮。

## 下载备份

1. 在左侧点 **设置**，再点 **备份** 标签页。
2. 点 **下载备份**，选一个保存位置。

<Shot name="settings-backup" cap="设置 · 备份" />

备份文件里有全部用户的订阅凭据和控制面的密钥。把它存在只有你能访问的地方，不要发给别人。

## 从备份恢复

恢复会整体替换控制面的数据，并且要重启控制面才生效，所以界面里不提供。需要恢复时，在这台已接入的电脑上安装 `mpx` 命令行，然后运行：

```bash
mpx restore mpx-backup.tar.gz
```

命令行的安装方法见[命令行](/reference/cli)。
