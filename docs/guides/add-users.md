# 添加用户并分发订阅

给一个人开账号，限定流量和到期日，再把订阅链接发给他。

前提：MPX 已接入控制面，至少有一个节点。

## 添加用户

1. 在左侧点 **用户**，再点右上角 **添加用户**。
2. 填写表单：
   - **用户名**：例如 `alice`，建好后不能改。
   - **套餐**：决定他能用哪些节点，每个套餐后面写着有几个节点。不确定就留「默认套餐」，它包含全部节点。见[用套餐分配节点](/guides/plans)。选了「没有节点」的套餐时，下面会出现灰色提示，**创建** 按钮暂时不能点：先给套餐加节点，或者换一个套餐。
   - **流量上限**：例如 `50GB`、`1.5TB`。留空表示不限。
   - **到期日**：格式 `YYYY-MM-DD`，按本机时区当天 23:59:59 截止。留空表示永不过期。
   - **更多选项** 里还有流量重置（不重置、每天、每周或每月）、额外授权和备注。
3. 点 **创建**。

<Shot name="user-new" cap="添加用户" size="dialog" />

保存后半分钟内生效，其他人不掉线。

::: details 用 Hysteria2 / TUIC 的注意
Hysteria2 / TUIC 节点由 sing-box 承载，用户名单一变会重启 sing-box，这台节点上的 Hysteria2 / TUIC 连接会断开一次。默认的 VLESS + REALITY（xray）不受影响。
:::

## 发订阅链接

创建后，同一个抽屉直接切到这个用户的详情，最上面是 **发给他**：

<Shot name="user-detail" cap="用户详情" />

让他用客户端扫二维码，或者点 **复制订阅链接** 发给他。客户端用这条链接会自动拿到它认识的格式；用浏览器打开，看到的是他自己的订阅页（用量、到期日、各格式链接和二维码）。客户端不认自动识别时，展开 **其他格式**，复制对应的那一条。

他的客户端第一次拉取订阅后，**发给他** 右边会写「Clash Verge 在 14:37 拉取过」这样的话，说明已经导入成功。

## 验证

回到 **用户** 列表。他的 **状态** 显示「正常」，就可以用了。快到期、用量快满的用户会出现在 **总览** 的「需要处理的用户」里。

## 常见调整

在用户列表里点这个用户，打开详情。编辑点右上角的铅笔，其他操作在 **⋯** 菜单里：

| 要做的事 | 操作 |
| :--- | :--- |
| 改流量上限、到期日、套餐、备注 | 铅笔（编辑） |
| 延长 30 天 | **续期 30 天** |
| 清零本期已用流量 | **清零本期用量** |
| 暂停使用，保留记录 | **停用**；之后可以 **启用** |
| 订阅链接泄露了 | **换一条新链接**，再把新链接发给他 |
| 永久删除 | **删除用户**，按提示输入用户名确认 |

**换一条新链接** 后旧链接马上失效，他的客户端要重新扫码或粘贴新链接才能更新订阅；已经连上的不会断。要立刻断开某人，用 **停用** 或 **删除用户**。停用和删除最多 30 秒后在节点上生效。
