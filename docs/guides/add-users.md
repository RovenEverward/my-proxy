# 添加用户并分发订阅

给一个人开账号，限定流量和到期日，再把订阅链接发给他。

前提：MPX 已接入控制面，至少有一个节点。

## 添加用户

1. 在左侧点 **用户**，再点右上角 **添加用户**。
2. 填写表单：
   - **用户名**：字母、数字、下划线、点和减号，1–64 位。
   - **套餐**：决定他能用哪些节点。不确定就留「默认套餐」，它包含全部节点。见[用套餐分配节点](/guides/plans)。
   - **流量上限**：例如 `50GB`、`1.5TB`。留空表示不限。
   - **到期日**：格式 `YYYY-MM-DD`，按本机时区当天 23:59:59 截止。留空表示永不过期。
   - **流量重置**：不重置、每天、每周或每月。
3. 点 **创建**。

<Shot name="user-new" cap="添加用户" />

新用户在 30 秒内同步到节点，节点不重启，其他人不掉线。

## 发订阅链接

创建后，右侧打开这个用户的详情。**订阅地址** 一节列出各种格式的链接：

<Shot name="user-detail" cap="用户详情" />

把 **自动识别** 那一行复制给他。客户端用这条链接会自动拿到它认识的格式；用浏览器打开，看到的是他自己的订阅页（用量、到期日、各格式链接和二维码）。

## 验证

回到 **用户** 列表。他的 **状态** 显示「正常」，就可以用了。快到期、用量快满的用户会出现在 **总览** 的「需要处理的用户」里。

## 常见调整

在用户列表里点这个用户，打开详情，在 **操作** 一节里：

| 要做的事 | 操作 |
| :--- | :--- |
| 改流量上限、到期日、套餐、备注 | **编辑…** |
| 延长 30 天 | **续期 30 天** |
| 清零本期已用流量 | **重置流量** |
| 暂停使用，保留记录 | **停用**；之后可以 **启用** |
| 订阅链接泄露了 | **吊销订阅**，再把新链接发给他 |
| 永久删除 | **删除用户**，按提示输入用户名确认 |

**吊销订阅** 只换订阅链接，已经连上的客户端不受影响。要立刻断开某人，用 **停用** 或 **删除用户**。停用和删除最多 30 秒后在节点上生效。
