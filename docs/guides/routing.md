# 设置分流规则

决定每个网站怎么走：直连、走代理，还是拦截。改完后，用户在客户端里更新订阅即可生效，节点不重启。

## 规则怎么生效

在左侧点 **分流规则**。规则从上往下比对，第一条对上的生效；都没对上的，走最下面一行 **其他全部** 的去向。

每条规则由三部分组成：

| 部分 | 可选值 |
| :--- | :--- |
| 类型 | 域名后缀、域名关键词、规则组（内置的一组域名，例如「广告拦截」）、IP 所在国家、IP 段 |
| 值 | 例如 `example.com`、`google`、`CN` |
| 去向 | 直连、拦截，或一个策略组（例如「自动选择」） |

## 加一条规则

假设你要 `example.com` 及其子域名直连：

1. 点 **添加规则**。
2. 类型选 **域名后缀**，值填 `example.com`，去向选 **直连**。
3. 保存。新规则加在最前面。

要调整顺序，按住规则左侧的拖动柄上下拖。规则右侧的开关可以临时停用一条规则，不用删除。

要加一整组域名（例如国内常见网站、流媒体），点 **内置规则组**，勾选后点 **添加所选**。

## 验证：测试一个网址

在右侧 **测试一个网址** 里输入域名，例如 `example.com`。结果显示它对上了第几条规则，最后从哪里出去。

## 只改某一个人的规则

右上角 **作用于** 默认是「全部用户（全局）」。选一个用户后，你加的规则只对他生效，并且排在全局规则前面。

## 策略组

规则的去向可以是一个策略组。策略组是一组节点，客户端在组内自动选最快的，或由用户手动选。

在 **策略组** 标签页里新建或修改。选节点的条件有地区、协议、标签和能力检测；右侧实时预览会选中哪些节点。
