# 一键更新

把整套 MPX 升到最新版：控制面和每台节点上的代理核心。管理台里点一次按钮，按顺序全部完成。操作机上的 `mpx` 命令行单独升，见文末。

## 更新

有新版本时，管理台右上角会出现 **更新** 按钮（控制面定期检查；没有这个按钮就说明全部已是最新）。

1. 点右上角 **更新**。弹窗列出控制面和每台节点的当前版本与目标版本，下面是这次的发布说明。
2. 点 **确认更新**。

<Shot name="update" cap="更新弹窗" size="dialog" />

MPX 依次升级控制面、节点，弹窗里逐条显示进度。控制面升完自动重启，页面刷新后用账号密码重新登录即可，数据不受影响。

暂时不想更新，点 **稍后**。同一个版本本次不再提示。

## 升级自己电脑上的 mpx

管理台的更新只管控制面和节点。你电脑上的 `mpx` 命令行：

```bash
mpx update apply cli
```

或者重新跑一遍安装脚本 / 下载新的 `mpx-cli_*` 安装包覆盖安装。

## 更新时用户会不会断线

- 升级控制面期间，用户照常上网，只是暂时不能拉新订阅、管理台暂时打不开。
- 升级某台节点的核心时，这台节点上的连接会断开一次，客户端会自动重连。

所以最好挑用的人少的时候更新。

## 验证

更新完成后，右上角的 **更新** 按钮消失。会话胶囊（右上角）里的版本号是控制面的新版本，**总览** 的「控制面」一格同样显示它。

## 出了问题

| 症状 | 处理 |
| :--- | :--- |
| 弹窗显示「更新失败」 | 失败那一行写明原因。修好原因后再点一次 **更新**；已经是新版本的部分会跳过 |
| 控制面升级后一直连不上 | SSH 上 VPS 看 `journalctl -u mpx-update -n 50`；健康检查不过时会自动换回上一版 |
| 页面一直显示「正在重启」超过 1 分钟 | 刷新页面重新登录 |

## 从老版本升上来

::: details 控制面是 v0.6.0 或更早装的
那时的控制面没有远程升级组件。在 VPS 上运行一次安装脚本补上，之后就能在管理台里更新：

```bash
curl -fsSL https://raw.githubusercontent.com/RovenEverward/my-proxy/main/deploy/install.sh \
  | sudo bash -s -- --addr 0.0.0.0:8080
```

`--addr` 要和控制面现在的监听地址一致。
:::
