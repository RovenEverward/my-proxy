# 让某个客户端拿到指定格式

某个客户端导入订阅后拿到的格式不对，例如拿到一串分享链接，而不是 Clash 配置。

## 判断它现在拿到什么

控制面按客户端请求里的 User-Agent，从上到下匹配客户端识别规则，第一条命中的决定格式。没有规则命中时返回分享链接（`links`），这不是错误。

在左侧点 **订阅**，向下滚到同一页的 **客户端识别** 段（旧地址 `#sub/clients` 会滚到 `#sec-clients`）：

## 加一条规则

假设客户端的 User-Agent 以 `MyClient/` 开头，你要它拿 sing-box 格式：

1. 点 **自定义规则**，在抽屉里点 **加一条**。
2. **User-Agent 正则** 填 `(?i)^myclient/`。`(?i)` 表示不区分大小写。
3. 格式选 **sing-box 配置**，用右侧 **↑** 移到第一条。
4. 点 **完成** 回到页面，再在底部保存条点 **保存**。

之后要调整顺序，用规则右侧的 **↑**、**↓**。

宽的规则会挡住后面的规则，例如 `(?i)clash` 也会命中 mihomo，所以具体的规则要放在前面。

结果可选 `clash-meta`、`clash`、`sing-box`、`xray`、`links`、`base64-links` 和 `block`。`block` 让该客户端拿不到订阅。

第一次改规则时，整张内置规则表会一起保存为你的规则；之后内置规则更新不再影响你。

## 验证

可以先在抽屉的 **试一个客户端** 中粘贴 User-Agent，看预览命中的规则；最终以控制面的 Go 正则匹配为准。保存后，在客户端里更新订阅，确认它拿到的配置类型对了。sing-box 格式是 JSON，Clash 格式是 YAML。

## 改回默认

在 **自定义规则** 抽屉点 **恢复内置**，再点 **完成**，最后在页面保存条点 **保存**。保存前只修改草稿。

## 不改规则的办法

让用户直接导入指定格式的链接。用户详情的 **订阅地址** 一节列出了每种格式各自的链接，例如 **Clash Meta** 那一行。
