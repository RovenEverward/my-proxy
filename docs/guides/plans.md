# 用套餐分配节点

让不同的人用不同的节点。例如：大部分人用全部节点，一部分人只用两台东京节点。

套餐是一组节点。每个用户挂一个套餐，他的订阅里只有这个套餐里的节点。

## 看现有的套餐

在左侧点 **套餐**。每一行显示套餐包含哪些节点、有多少人在用。

<Shot name="plans" cap="套餐" />

**默认套餐** 打开了「全部节点」，以后新加的节点也会自动包含进去。新用户默认挂在它上面。默认套餐可以编辑，不能删除。

## 新建一个套餐

1. 点右上角 **新建套餐**。
2. 填 **名字**，例如 `亚洲`。
3. 在 **节点** 列表里勾选要包含的节点。勾选的节点以后新加的入站也会自动包含。
4. 右侧「挂这个套餐的用户会拿到」实时列出这些节点上的入站。确认后点 **保存**。

<Shot name="plan-detail" cap="编辑套餐" />

## 把用户挂到套餐上

- 新用户：在 **添加用户** 表单里选 **套餐**。
- 已有用户：在用户详情里点 **编辑…**，改 **套餐**，保存。

用户在下次更新订阅时拿到新的节点列表。

## 验证

回到 **套餐** 页，这个套餐的人数加了 1。打开用户详情，**套餐** 一行显示新套餐的名字。

## 删除套餐

在套餐详情左下角点 **删除**。还有用户挂在上面时，要先选 **这些用户改挂到** 哪个套餐，才能删除。
