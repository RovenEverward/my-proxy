# 混合外部订阅与自建节点

MPX 可以拉取已有的外部订阅，并将节点加入指定用户的 MPX 订阅。客户端继续使用原来的 MPX 地址。

## 添加外部订阅

1. 打开 **订阅**。
2. 点 **管理外部订阅**。
3. 点 **添加订阅**。
4. 输入来源名称和订阅地址。
5. 设置刷新间隔。默认每 6 小时刷新；填 `0` 表示仅手动刷新。
6. 点 **添加并拉取**。

来源详情显示有效节点数、刷新状态和格式兼容结果。来源刚添加时，没有任何用户获得授权。

控制面负责定时拉取。关闭电脑上的管理窗口，不会停止控制面的刷新任务。

## 选择接收用户

1. 打开来源详情。
2. 在 **接收用户** 中勾选用户。
3. 点 **保存接收用户**。
4. 在页面下方查看该用户的混合订阅预览。
5. 让客户端刷新原来的 MPX 订阅。

外部来源授权独立于自建节点和套餐。原来的“全部入站”权限不包含外部来源。新用户也不会自动获得外部来源。

**Note：** 接收用户共享上游节点的凭证。撤回授权后，MPX 不再向该用户提供这些节点。已经保存的上游凭证仍可能可用。需要使这些凭证失效时，请在上游服务中轮换凭证。

## 将节点加入策略组

在 **分流 → 策略组** 中，可以按来源收录节点：

| 来源条件 | 结果 |
| --- | --- |
| 不选择来源 | 收录用户有权使用的全部来源 |
| 自建节点 | 仅收录自建节点 |
| 指定外部来源 | 仅收录所选来源 |
| 自建节点与指定来源 | 混合收录两类节点 |

来源条件与地区、协议和能力条件同时生效。外部节点默认没有地区和能力检测结果。它不能满足对应的地区或能力条件。

来源详情可以设置一个默认地区。这个值是操作者提供的分类，不代表系统已确认实际出口地区。

策略组编辑器支持按用户预览。页面下方的混合预览会指出“节点已收录，但未进入策略组”。需要一个包含两类节点的组时，可以创建不限制地区和能力的混合组。规则去向仍由操作者设置。

## 刷新、停用与删除

- 手动刷新与定时刷新共用同一个任务。同一来源重复点击刷新，不会并发拉取。
- 刷新失败时，MPX 保留上次有效节点，并显示错误和快照时间。
- 空列表或完全不兼容的响应不会清空旧快照。
- 修改地址后，旧结果会保留到新地址刷新成功。需要先移除旧结果时，先停用来源。
- 停用来源会停止定时拉取，并从后续订阅输出中移除节点。配置和授权仍保留。
- 删除来源会同时删除快照与授权。其他来源及自建节点保留。

删除来源不会使已经保存的上游凭证失效。引用已删除来源的策略组条件会保留，避免条件意外扩大为全部来源。

## 支持的格式

输入支持 Clash／mihomo 的内联 `proxies`、sing-box 的独立代理 `outbounds`、明文分享链接和 Base64 链接列表。

基础协议包括 VLESS、VMess、Trojan、Shadowsocks、Hysteria2 和 TUIC。连接所需字段无法完整保留时，MPX 会跳过该节点并说明原因。例如，需要插件、混淆、拨号链或特定证书配置的节点可能无法导入。

MPX 保留现有六种输出格式。不同格式能表达的节点不同。来源详情会显示每种格式的实际输出数及跳过原因。

MPX 使用自己的 DNS、分流规则和策略组。外部订阅中的完整规则配置不会覆盖这些设置。仅通过 `proxy-providers` 间接提供的节点不会被继续拉取。

## 用量与用户状态

MPX 的流量和额度只统计自建节点。外部来源的额度与到期由上游服务管理，不能与 MPX 用量相加。

用户停用、过期或达到 MPX 流量上限时，整份订阅返回现有状态占位。已经保存的外部凭证仍由上游控制。

## 命令行

通过交互输入订阅地址，可以避免地址进入命令历史：

```bash
mpx source add "常用订阅"
mpx source list
mpx source show 1
mpx source grant 1 --user alice
mpx source preview --user alice --format sing-box
mpx source refresh 1
mpx source revoke 1 --user alice
mpx source disable 1
mpx source enable 1
mpx source delete 1
```

`source add` 默认等待首次拉取结束。刷新失败会返回非零退出码，来源记录仍保留，便于修改或重试。使用 `--wait=false` 可以立即返回。

自动化时，可通过标准输入提供 URL：

```bash
mpx source add "手动来源" --url-stdin --interval 0
mpx source edit 1 --url-stdin
mpx source edit 1 --interval 12h
```

运行这两个带 `--url-stdin` 的命令时，应由调用方提供标准输入。

来源条件使用独立接口保存。旧版本保存用户或策略组，不会清空来源授权或来源条件。

```bash
mpx group add "混合节点" --source managed,source:1 --mode manual
mpx group preview "混合节点" --user alice
mpx group edit "混合节点" --source managed
```

来源地址、上游凭证和授权随控制面数据库备份恢复。请按[备份指南](./backup)保护备份文件。
