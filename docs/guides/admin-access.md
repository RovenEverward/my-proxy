# 管理台访问

管理台由控制面自己伺服，挂在 `/admin/`。本页讲：地址是什么、怎么登录、忘了密码怎么办、别的电脑怎么接入 CLI、怎么踢掉丢失的凭据。

## 管理台地址

- **配了域名（推荐）：** `https://<域名>/admin/`。域名托管在 Cloudflare、API token 填进 **系统 → 域名与证书** 并签出证书后，任意浏览器直接可开。
- **没配域名：** `/admin/` 只受理 TLS 或回环请求。裸 IP + 自签证书浏览器不认，走 SSH 隧道到回环最省事：

  ```bash
  ssh -N -L 8080:127.0.0.1:8080 root@<控制面地址>
  # 浏览器打开 http://127.0.0.1:8080/admin/
  ```

  控制面监听端口不是 8080 时把两处 8080 都换掉。

## 登录

- 用户名和密码就是 `mpx init` 时设的管理员账号（默认用户名 `admin`）。
- 网页与 `mpx connect` 共用同一套账号。
- 同一 IP 连续输错太多次会锁定 15 分钟，页面会告诉你还要等多久。

## 忘了密码

网页没有自助找回，需要在服务器上重置。SSH 登录控制面所在 VPS，运行：

```sh
sudo sh -c 'MPX_TOKEN="$(sed -n "s/^MPX_TOKEN=//p" /etc/mpx/env)" mpx --server http://127.0.0.1:8080 admin password'
```

按提示输入旧密码留空不管（救援通道不验旧密码）、输入两次新密码。**改完全部浏览器会话与 CLI token 立即失效**，各处用新密码重新登录。

::: details 还没有管理员账号（比如从很老的版本升上来）
同一条救援路径建号：

```sh
sudo sh -c 'MPX_TOKEN="$(sed -n "s/^MPX_TOKEN=//p" /etc/mpx/env)" mpx --server http://127.0.0.1:8080 admin create --username admin'
```

:::

## 在别的电脑上用命令行

1. 装 `mpx`（见[快速开始](/tutorial/quickstart)第 1 步）。
2. 用管理员账号密码接入——`mpx init` 结束时打印过带指纹的完整命令，直接照敲；没有指纹时它会先摆出证书指纹让你确认：

   ```bash
   mpx connect <域名或IP>:8080 --username admin
   ```

   控制面只监听回环时，先拉 SSH 隧道再 `mpx connect 127.0.0.1:8080`。
3. 管多套控制面时用 `--profile <档名>` 分开存；`--profile` 或 `MPX_PROFILE` 选档。

接入后 `mpx` 命令直接可用，不需要再进浏览器。

## 踢掉丢失的凭据

设备丢了或怀疑密码泄露：**改密码**。在服务器上跑上面的 `mpx admin password`（或在已知密码的情况下用 `PUT /api/admin/password` 等价命令），改完全部会话与 CLI 凭据即刻失效——包括正在用的这台，重新登录即可。没有「只踢某一台」的粒度，这是单管理员模型的取舍。

## 出了问题

| 症状 | 原因 | 处理 |
| :--- | :--- | :--- |
| 浏览器打不开 `/admin/` | 明文公网请求不受理 | 配域名走 HTTPS，或 SSH 隧道到回环 |
| 打开是浏览器证书警告页 | 控制面还在用自签证书 | 配域名签 ACME 证书；隧道回环则没有警告 |
| 「登录已锁定」 | 同 IP 连续输错太多次 | 等锁定时间到再试；已登录会话不受影响 |
| 所有会话突然都要重登 | 有人改了管理员密码 | 确认是否你改的；不是就立即重置密码 |
| `mpx connect` 报指纹不符 | 控制面重装过、换了证书，或有人在中间冒充 | 确认是前者后用 `--fp` 带上新指纹重新接入 |
