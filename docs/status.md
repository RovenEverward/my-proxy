### 一、漏项在实现末段才暴露

**对策**:能力清单要按「目标里的每一项」逐条对,而不是按「讨论中提到的」。这就是下面那张对照表的来源。

### 二、边界值没定义会变成不报错的空转

`reset_strategy` 的取值没定义过「认不出怎么办」。实现出来是:

```
ResetPeriod("") 返回 0
  → 每轮「推进」完还是同一时刻
  → 后台任务死循环、永不返回、不报错
  → 采样与收敛全部静默停摆
```

修法是三层一起:

- **模型层**让非法值不参与轮转(`NextResetAt` / `AdvanceReset` 认不出就返回原值);
- **入口层**把空串归一成 `none`,把认不出的值拒绝掉;
- **测试**三层各加一条。

**对策**:枚举、策略、状态类字段,设计时就要写明「认不出的取值怎么办」。
