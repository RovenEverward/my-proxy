# 快速开始

完成本页后，你的 VPS 同时运行控制面和一个代理节点，你手里有一条可以导入客户端的订阅链接。全程在 MPX 桌面程序的窗口里操作，大约 10 分钟。

## 准备

- 一台 Linux VPS，有公网 IP，能用 root 通过 SSH 登录。你需要它的 IP 和 root 密码。
- 你自己的电脑：macOS、Windows 或 Linux。

## 第 1 步：安装 MPX

打开[最新发布页](https://github.com/RovenEverward/my-proxy/releases/latest)，按你的系统下载桌面安装包：

| 系统 | 下载 | 安装 |
| :--- | :--- | :--- |
| macOS（Intel 与 Apple 芯片） | `mpx-desktop_<版本>_darwin_universal.dmg` | 打开后把 MPX 拖进「应用程序」 |
| Windows（64 位） | `mpx-desktop_<版本>_windows_amd64_setup.exe` | 双击安装，不需要管理员权限 |
| Debian / Ubuntu | `mpx-desktop_<版本>_amd64.deb`（ARM 用 `arm64`） | 双击安装 |
| 其他 Linux | `mpx-desktop_<版本>_linux_amd64.tar.gz` | 解压后在 `MPX/` 目录运行 `./install.sh` |

安装包没有签名，第一次打开时系统会拦一下：

- **macOS**：在「应用程序」里右键 MPX →「打开」，再点「打开」。也可以在「系统设置 → 隐私与安全性」里点「仍要打开」。
- **Windows**：SmartScreen 提示时点「更多信息」→「仍要运行」。

Linux 桌面版需要系统的 WebKitGTK 4.1（Debian / Ubuntu 的包名是 `libwebkit2gtk-4.1-0`，装 `.deb` 时会自动装上）。

## 第 2 步：打开 MPX，开始首次安装

打开 MPX。还没有接入任何控制面时，窗口显示首次安装向导：

<Shot name="setup-welcome" cap="首次安装：欢迎页" />

点 **首次安装（新服务器）**。已经有控制面的话，点 **接入已有控制面**，见[在多台设备上管理](/guides/devices)。

## 第 3 步：填 VPS 的地址和密码

<Shot name="setup-host" cap="首次安装：连接 VPS" />

1. **服务器地址** 填 VPS 的公网 IP，例如 `203.0.113.10`。
2. **登录方式** 选 **SSH 密码**，在 **root 密码** 里填 VPS 的 root 密码。
3. 点 **检查机器**。

MPX 用这个密码登录一次，把这台电脑的公钥装到 VPS 上，之后全程改用密钥。密码不保存。

检查通过后，窗口显示「可以安装」。点 **下一步**。

## 第 4 步：设设备密码，开始安装

在 **设置** 这一步：

1. **第一个用户** 和 **节点名** 填你想用的名字，例如 `alice` 和 `tokyo`。
2. 设一个**设备密码**，至少 12 个字符，**再输一次** 确认。以后别的电脑接入这个控制面时输入它。它不是 VPS 的密码。
3. 点 **开始安装**。

窗口逐项显示安装进度，每一步打勾后进入下一步，全部完成后进入 **完成** 页。某一步失败时，窗口显示失败原因和日志，改好后点 **重新运行**。

## 第 5 步：导入订阅

**完成** 页显示第一个用户的订阅链接和二维码：

- 手机客户端：扫二维码。
- 电脑客户端（Clash Verge、sing-box、v2rayN 等）：点复制按钮，把链接作为订阅导入。

客户端会自动拿到它认识的格式。点 **进入管理界面**，你会看到总览页：

<Shot name="overview" cap="总览" />

从现在起，你不需要再登录 VPS。

::: tip 不用配证书
控制面在 `8080` 一个端口上同时提供订阅和管理接口。管理接口用控制面自己生成的证书加密，MPX 按证书指纹认它，所以不需要域名和反向代理。
:::
