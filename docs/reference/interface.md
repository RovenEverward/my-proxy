# 界面

MPX 桌面窗口左侧是导航，分「管理」和「配置」两组。本页列出每一页能做什么。

## 窗口顶部和左上角

| 位置 | 内容 |
| :--- | :--- |
| 左上角版本号 | 桌面程序的版本 |
| 配置档卡片 | 当前连着的控制面和它的地址。圆点绿色表示连得上，红色表示最近一次没连上。点它打开配置档列表：每项显示证书指纹前 16 位，点一项切换过去；**添加控制面…** 接入另一套控制面并切过去 |
| 右上角 **更新** | 有新版本时出现，见[一键更新](/guides/update) |
| 右上角刷新、深浅色按钮 | 重新读取数据；切换浅色或深色 |

## 各页面

| 页面 | 能做的事 | 指南 |
| :--- | :--- | :--- |
| 总览 | 用户、节点、入站的统计；需要处理的用户；节点状态；通知设置 | — |
| 用户 | 添加、编辑、续期 30 天、重置流量、停用 / 启用、吊销订阅、删除；按状态和套餐筛选；查看订阅链接 | [添加用户并分发订阅](/guides/add-users) |
| 套餐 | 新建、编辑、删除套餐；查看每个套餐的节点和人数 | [用套餐分配节点](/guides/plans) |
| 节点 | 添加节点向导；现场检查、下发配置、排水、体检、安装核心、在线用户、配置预览、删除；批量识别显示名 | [添加节点](/guides/add-nodes) |
| 入站与入口 | 入站（节点上监听的协议和端口）和对外入口（客户端连接用的地址）的增删改 | [控制面与节点](/concepts/architecture) |
| 分流规则 | 规则的添加、拖动排序、停用、删除；「其他全部」的去向；某个用户的专属规则；内置规则组；策略组；测试一个网址 | [设置分流规则](/guides/routing) |
| 自检 | 逐项检查控制面、节点和订阅格式 | [用自检排查](/guides/troubleshoot) |
| 设置 | 通用、识别规则、模板、设备、备份 | [订阅设置](/reference/settings) · [在多台设备上管理](/guides/devices) · [备份控制面](/guides/backup) |

界面里节点一律用**显示名**（如 🇯🇵 东京 A，由地区、城市和字母组成）。每台节点另有一个**内部名**（如 `node-1`），添加节点时自动生成，只在命令行和数据里用；界面上只在节点详情和编辑的 **高级** 里看得到。

### 节点详情里的操作

| 操作 | 作用 |
| :--- | :--- |
| **现场检查** | 立刻登录节点查看运行状态，不等下一轮巡检 |
| **下发配置** | 把当前配置推到节点并重启核心；新增入站、改端口、换证书后要点它才生效，该节点上的连接会断开一次 |
| **排水** | 暂停给这台节点分配新连接，方便下线维护：新订阅不再包含它，已连上的用户下次刷新订阅时换到别的节点；点 **结束排水** 恢复 |
| **体检** | 在节点上检查健康状况和出口能力，最长要十几分钟 |
| **安装核心** | 在节点上安装 xray 或 sing-box，下发当前配置并启动 |
| **在线用户** | 查看现在连着这台节点的用户 |
| **配置预览** | 查看即将下发到节点的配置 |
| **删除节点** | 删除节点和它的入站，订阅里不再有它；机器上的核心不清理。按提示输入内部名确认 |

还没有接入控制面时，窗口显示首次安装向导，可以装一台新服务器，或接入已有控制面。见[快速开始](/tutorial/quickstart)。

## 需要确认的操作

| 操作 | 怎样确认 |
| :--- | :--- |
| 删除用户、删除节点、删除入站 | 逐字输入名字（节点输入内部名，入站输入标签） |
| 停用用户、吊销订阅、重置流量、下发配置、排水、安装核心、体检、吊销设备 | 在弹窗里点确认 |

## 界面里不提供的操作

| 操作 | 原因 | 办法 |
| :--- | :--- | :--- |
| 从备份恢复 | 整体替换数据并重启控制面 | `mpx restore`，见[备份控制面](/guides/backup) |
| 导入、导出用户 CSV | 要读写本机文件 | `mpx user import`、`mpx user export`；**用户** 页的 **导出 CSV** 会复制导出命令 |
| 测试某个 User-Agent 拿到什么格式 | 规则是 Go 正则，窗口里的引擎与它不一致 | `mpx settings rules test` |

命令行见[命令行](/reference/cli)。

## 安全

- 窗口只和本机的 MPX 进程通信，控制面的凭据不进页面。
- 本地页面只接受本机（回环地址）的请求。
- 发给控制面的请求只限一份白名单。
