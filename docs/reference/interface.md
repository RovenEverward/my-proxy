# 界面

MPX 桌面窗口左侧是导航，从上到下就是使用顺序：**总览**、**节点**、**用户**、**订阅**、**分流**，分隔线下面是 **体检** 和 **系统**。本页列出每一页能做什么。

## 窗口顶部和左上角

| 位置 | 内容 |
| :--- | :--- |
| 左上角版本号 | 桌面程序的版本 |
| 控制面卡片 | 当前连着的控制面的名称和地址。圆点是黑色（深色模式下是白色）表示连得上，红色表示最近一次没连上。点卡片展开：地址、证书指纹（4 位一组）、这台电脑在控制面上登记的设备名，以及 **复制指纹**、**切换控制面** 两个按钮。**切换控制面** 里每项显示名称和地址，点一项切换过去，下次打开 MPX 仍连这一套；**添加控制面…** 接入另一套控制面并切过去 |
| 右上角 **更新** | 有新版本时出现，见[一键更新](/guides/update) |
| 右上角刷新、深浅色按钮 | 重新读取数据；切换浅色或深色 |

## 各页面

| 页面 | 能做的事 | 指南 |
| :--- | :--- | :--- |
| 总览 | 刚装好时是「开始使用」清单（节点在线、订阅地址、第一个用户、把订阅发给他），4 步走完收成一行；用户、节点、近 24 小时在用的统计；需要处理的用户；节点状态；通知设置。有节点连不上时，侧栏的 **总览** 后面亮一个红点 | — |
| 节点 | 添加节点向导；节点详情里管 **连接方式**（添加连接、再加一个入口、编辑），以及刷新状态、应用到节点、暂停分配、体检、安装核心、在线用户、配置预览、删除；批量识别显示名 | [添加节点](/guides/add-nodes) |
| 用户 | **用户** 页签：添加、编辑、续期 30 天、清零本期用量、停用 / 启用、换一条新链接、删除；按状态和套餐筛选；用户详情最上面是「发给他」（二维码、复制订阅链接、其他格式、客户端拉取状态）。**套餐** 页签：新建、编辑、删除套餐，查看每个套餐的节点和人数 | [添加用户并分发订阅](/guides/add-users) · [用套餐分配节点](/guides/plans) |
| 订阅 | **地址与显示**（订阅地址、标题、刷新间隔、支持链接）；**客户端识别**（按客户端决定发哪种格式）；**订阅底稿**（Clash / sing-box / Xray 的底稿，属于高级设置） | [订阅设置](/reference/settings) |
| 分流 | 规则的添加、拖动排序、停用、删除；「其他全部」的去向；某个用户的专属规则；内置规则组；策略组；测试一个网址 | [设置分流规则](/guides/routing) |
| 体检 | 逐项检查控制面、节点和订阅格式 | [用体检排查](/guides/troubleshoot) |
| 系统 | **通知**（Webhook、到期和用量提醒）；**设备与接入**；**备份与恢复**；**更新与版本** | [在多台设备上管理](/guides/devices) · [备份控制面](/guides/backup) · [一键更新](/guides/update) |

界面里节点一律用**显示名**（如 🇯🇵 东京 A，由地区、城市和字母组成）。每台节点另有一个**内部名**（如 `node-1`），添加节点时自动生成，只在命令行和数据里用；界面上只在节点详情和编辑的 **高级** 里看得到。

### 节点详情里的操作

头部只在有改动未应用、节点上的配置和控制面不一致或从未应用过时显示 **应用到节点** 主按钮；其余时候 **应用到节点** 和 **刷新状态**、**暂停分配 / 恢复分配**、**编辑** 一起收在 **⋯** 菜单里。

| 操作 | 作用 |
| :--- | :--- |
| **刷新状态** | 立刻登录节点查看运行状态，不等下一轮巡检 |
| **应用到节点** | 把当前配置推到节点并重启核心；新增入站、改端口、换证书后要点它才生效，该节点上的连接会断开一次。添加、编辑、删除连接时默认「…并应用到节点」一步做完；选了「稍后应用」的节点，连接方式卡片会显示「有改动未应用」，详情头部会出现「应用到节点」主按钮 |
| **暂停分配** | 暂停给这台节点分配新连接，方便下线维护：新订阅不再包含它，已连上的用户下次刷新订阅时换到别的节点；点 **恢复分配** 恢复 |
| **体检** | 在节点上检查健康状况和出口能力，最长要十几分钟 |
| **安装核心** | 在节点上安装 xray 或 sing-box，应用当前配置并启动 |
| **在线用户** | 查看现在连着这台节点的用户 |
| **配置预览** | 查看 **应用到节点** 会推过去的配置 |
| **删除节点** | 删除节点和它的入站，订阅里不再有它；机器上的核心不清理。按提示输入内部名确认 |

还没有接入控制面时，窗口显示首次安装向导，可以装一台新服务器，或接入已有控制面。见[快速开始](/tutorial/quickstart)。

## 需要确认的操作

| 操作 | 怎样确认 |
| :--- | :--- |
| 删除用户、删除节点、删除入站 | 逐字输入名字（节点输入内部名，入站输入标签） |
| 停用用户、换一条新链接、清零本期用量、应用到节点、暂停分配、安装核心、体检、吊销设备 | 在弹窗里点确认 |

## 界面里不提供的操作

| 操作 | 原因 | 办法 |
| :--- | :--- | :--- |
| 从备份恢复 | 整体替换数据并重启控制面 | `mpx restore`，见[备份控制面](/guides/backup) |
| 导入、导出用户 CSV | 要读写本机文件 | `mpx user import`、`mpx user export`；**用户** 页的 **导出 CSV** 会复制导出命令 |
| 测试某个 User-Agent 拿到什么格式 | 规则是 Go 正则，窗口里的引擎与它不一致 | `mpx settings rules test` |

命令行见[命令行](/reference/cli)。

## 安全

- 窗口只和本机的 MPX 进程通信，控制面的凭据不进页面。
- 本地页面只接受本机（回环地址）的请求。
- 发给控制面的请求只限一份白名单。
