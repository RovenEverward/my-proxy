# 运维手册(runbook)

日常要做的几件事,每件一节:什么时候做、照着做、怎么确认做对了、出事怎么退。
原理见 [安装与升级](../atlas/install-update.md);用户视角的步骤见文档站的
[一键更新](../guides/update.md)。文中地址一律用示例(203.0.113.10)。

## 1. 发一个版本

**什么时候:** 一批影响用户的改动合进 main,三平台 CI 全绿。

1. 在 `CHANGELOG.md` 顶部写好 `## vX.Y.Z (日期)` 一节(新增 / 改进 / 修复 / 兼容性),随改动的 PR 一起合进 main。
2. 用这一节当注解 tag 的正文,原样保留 Markdown(`--cleanup=verbatim`,否则 `#` 开头的标题行会被当成注释删掉):

   ```bash
   awk '/^## vX.Y.Z/{f=1;next} /^## v/{f=0} f' CHANGELOG.md > /tmp/notes.txt
   git tag -a vX.Y.Z --cleanup=verbatim -F /tmp/notes.txt
   git push origin vX.Y.Z
   ```

3. 等 `release` 工作流跑完(命令行归档、桌面归档、安装包、`SHA256SUMS`、publish 全部 success)。

**确认:** 发布页是正式版(不是 pre-release);资产清单与上一版同构(版本号以外的名字一致),`SHA256SUMS` 在;正文第一行是 `### 新增` 一类的标题而不是空的。

**出事:** 工作流某个平台失败 → 修好后删掉这个 tag 和草稿发布,重打同一个 tag(还没人下载过时);已经有人升级了就发下一个补丁版本,不要改已发布版本的文件。

## 2. 把一套部署升到新版本

**什么时候:** 发版后。

1. **先拍快照**(只读):每个用户的六种订阅各取一份算哈希,记下 `mpx node list -o json` 里每台节点的可达、核心版本和配置哈希,以及 `mpx status` 的版本。
2. 在桌面窗口点右上角 **更新** → 看三层(桌面程序、控制面、每台节点)的当前与目标版本 → **重启以更新**。顺序是控制面 → 节点 → 桌面程序,桌面程序最后原地重启。
3. **再拍一次快照**并逐个比对。

**确认:** 控制面版本变成新版本;订阅内容逐字节不变(除非这一版本来就改了订阅);节点都可达、核心在跑、配置哈希不变(没改核心版本时)。

**出事:**
- 控制面健康检查不过 → 执行器自动换回上一版的符号链接;看 VPS 上 `journalctl -u mpx-update -n 50`。
- 某台节点核心升级失败 → 这一台自动回滚、整批停下;修好后重点一次 **更新**,已升好的会跳过。
- 桌面程序没写权限(`.deb` 装在 `/opt/mpx`)→ 下载新的 `mpx-desktop_` 安装包覆盖安装。

## 3. 在 VPS 上补跑安装脚本

**什么时候:** 控制面是 v0.6.0 或更早(没有远程升级组件),或者 systemd 单元被改坏。

```bash
curl -fsSL https://raw.githubusercontent.com/RovenEverward/my-proxy/main/deploy/install.sh | sudo bash -s -- --addr 0.0.0.0:8080
```

- 重复跑是安全的:token、数据库、SSH 密钥都不动。
- `--addr` 写现在的监听地址。v0.9.1 起不写也会沿用现有 `mpx.service` 里的地址;`mpx-update.service` 健康检查的地址从 v0.9.2 起也跟着它走。
- 取不到最新版的 `SHA256SUMS` 时脚本拒绝安装(v0.9.2 起),检查网络后重跑。

**确认:** `systemctl is-active mpx`;`systemctl cat mpx mpx-update | grep -- --addr` 两处端口一致;客户端能拉订阅。

## 4. 备份与恢复控制面

见文档站 [备份控制面](../guides/backup.md)。要点:备份不含管理 token;恢复是「校验 + 暂存」,下次启动时换入,旧库改名留作回退。

## 5. 机器上不能做的事

- 不要在节点上手改 xray / sing-box 配置:下次下发会被覆盖,自检会报漂移。
- 不要停掉或改写和 MPX 无关的服务(同机的其他代理进程、它们的配置)。
- 删除用户、节点、整库这类不可逆操作,先备份,再在界面里逐字确认。
