# 用户 CSV 导入导出规格 (CSV Format)

本文档定义 `mpx user export` 与 `mpx user import` 交互使用的 CSV 文件的格式规范、字段约束与解析行为。

---

## 1. 结构与列名定义

CSV 第一行必须为表头。系统按**列名**（不分列出现的前后顺序）解析字段，忽略未识别的未知列。

标准 7 列定义如下：

| 列名 (表头) | 数据类型 | 留空语义（默认值） | 示例取值 | 规格与合法性要求 |
| :--- | :--- | :--- | :--- | :--- |
| **`用户名`** | `string` | *(必填，不可空)* | `alice` | 用户唯一标识，仅限小写字母、数字与下划线。 |
| **`流量上限`** | `string` | `不限` (0 字节) | `100GB`, `500MB` | 支持 `MB`、`GB`、`TB` 单位（按 1024 进制解析，`1GB = 1073741824` 字节）。 |
| **`到期时间`** | `string` | `不过期` (永久) | `2026-12-31` | 标准日期 `YYYY-MM-DD`。导入时自动解析为当地时区当天的 `23:59:59`。 |
| **`可用性`** | `string` | `启用` (`active`) | `启用` 或 `停用` | 支持中文 `启用` / `停用`，布尔值 `true` / `false`，或数字 `1` / `0`。写错会直接阻断报错。 |
| **`重置策略`** | `string` | `none` (从不) | `monthly`、`none` | `none`（累计用量不归零）、`daily`（每 24 小时）、`weekly`（每 7 天）或 `monthly`（每月 1 日重置用量）。写错会直接阻断报错。 |
| **`入站范围`** | `string` | `全部` (所有入站) | `1,2` | 允许该用户连接的 Inbound ID 列表，用英文逗号隔开。 |
| **`备注`** | `string` | `""` (无备注) | `VIP 会员` | 任意文本，通常记录用户联系方式或业务备注。 |

---

## 2. 导出与导入样本

### 样例文件 (`users.csv`)

```csv
用户名,流量上限,到期时间,可用性,重置策略,入站范围,备注
alice,100GB,2026-12-31,启用,monthly,,核心研发组
bob,200GB,2027-06-30,启用,none,1,仅限香港入口
charlie,,,停用,none,,临时挂起测试
david,50GB,2026-11-01,启用,monthly,1,2,销售外勤
```

---

## 3. 导入行为与幂等性规则

1. **Upsert 策略**：
   - 如果 CSV 中的用户名在系统中**不存在**，执行新增用户逻辑，系统会自动为其随机生成底层协议密钥（Key）和订阅令牌（SubToken）。
   - 如果该用户名**已存在**，系统将仅使用 CSV 中的 7 列属性**覆盖**已有用户的配置，**不会修改该用户现有的已用流量统计（`used_traffic`）**，也不会轮换其底层协议密钥与订阅链接。
2. **容错机制**：
   - 逐行独立提交事务。如果某一行格式错误（如非法的日期格式或未知的可用性枚举），系统会报错跳过该行，不影响其余合法行的数据导入。
   - 导入完成后，CLI 终端会打印出汇总报告：`导入完成: X 个新增, Y 个更新, Z 个失败`。
