# 节点一键体检

一条命令检查节点健康、全部代理入口、出口与流媒体能力、延迟丢包、线路证据、多站小样本测速和 IP 信息，最后汇总为同一份报告。

```bash
# 一键检查一个节点
mpx node diagnose 1

# 一键检查全部节点，逐个执行，某个节点失败仍继续其余节点
mpx node diagnose --all

# 查看最新完整报告，不重新消耗流量
mpx node diagnostics 1

# 结构化输出
mpx node diagnose --all -o json
```

不需要分别执行状态、能力和测速命令。完整体检先查看 SSH、核心服务、配置漂移与证书状态，再测节点网络，然后逐个通过已配置的真实代理入口检测出口 IP、YouTube 连通性与 Netflix 页面证据。入口检测使用已有的活跃且获授权的用户；无可用用户、动态专属域名、排空或入口异常都会写入报告。

一键报告区分本次入口观察与需要两次一致观察的稳定能力状态。不会为了等稳定状态而自动重复测试；Netflix 未能取得可靠证据时保留未知，YouTube 成功只说明连通性。原有能力检测结果仍可用于用途订阅的筛选，网络测速不会自动剔除用途候选。

## 默认预算

完整体检默认开启有限流量的多站上传下载：Cloudflare anycast 接口和 LibreSpeed 官方注册表列出的 Clouvider 洛杉矶站，每站每方向请求 1 MiB。网络体检 HTTP 预算为 32 MiB，默认最多 120 秒；单次请求 5 秒，延迟采样 3 次。完整流程另包含节点健康和逐入口能力检测，总时限为 6 分钟。

入口能力检测有自己的正文与时间上限：每个入口最多四次请求，每次正文最多 8 MiB（通常远小于上限），单入口最长 65 秒。32 MiB 是网络体检的应用数据预算，不包含这些单独列出的入口请求，也不包含 HTTP 头、TLS、TCP 重传。完整报告显示各部分结果与预算；全部节点按相同限制逐个检查。

```bash
# 保留完整检查，关闭测速
mpx node diagnose 1 --speed=false

# 调整网络部分流量和时间预算
mpx node diagnose 1 --max-bytes 16777216 --speed-bytes 1048576 --timeout 120s
```

Clouvider 下载以 1 MiB 块为单位，较小或非整数 MiB 配置会向上取整并按实际请求量预留预算。上传成功表示客户端发送完成且站点返回成功，Clouvider 不提供服务端接收字节回执。小样本包含握手和请求耗时，不能代表线路长期最大带宽。

服务端一次只运行一个体检；同节点同测量位置至少间隔一分钟。独立于流量采样，不修改部署或用户配额。每节点只保存 node/control 各一份最新报告，取消时尽量保留部分证据。报告带测量时间和开始时的节点地址；后续编辑节点地址不会改写旧报告。

## 看懂结果

结果区分正常、部分成功、失败和跳过，每项附具体原因。执行机器缺少工具或权限、目标拒绝、预算耗尽、超时、缺少 API 密钥都会直接显示。使用已安装的 curl、ping、mtr 或 traceroute，不自动安装软件。

- 节点健康反映 SSH、核心服务、配置哈希与证书；摘要指出明确问题，不生成笼统质量评分。
- ICMP 延迟是 Echo RTT，丢包按实际探测统计；HTTP 延迟是 curl time_total，包括连接、TLS 与响应体完成，失败率单独统计。
- 抖动是相邻成功样本差值绝对值的均值；样本不足时保留未知。
- 路由是节点到目标的单方向证据，不能证明回程。中间路由器限制回复时，高丢包或星号不代表转发丢包。
- ASN 表示 IP 注册归属，不能当作完整 BGP AS 路径或凭此判断 CN2、CMI 等线路等级。
- IPv4、IPv6 分别记录实际出口；GeoIP、供应商标记和信誉查询关联所选地址，不能把一个地址的结果推广到两族 IP。

## 可选 IP 数据

无需密钥可获取出口 IP 及 ipwho.is 的 GeoIP/ASN。地理位置不是物理机房位置保证；免费来源没有提供机房、VPN 或代理标记时保留未知。

在执行机器设置 MPX_IPAPI_IS_KEY 后，可查询 ipapi.is 原始机房、VPN、代理、Tor 和滥用标记。字段缺失保持未知；免费注册密钥每日 1000 次，工具不自动匿名回退或重试限流。

MPX_ABUSEIPDB_KEY 可补充社区举报置信度，它是供应商数据，不代表安全保证。远程 API 不接收密钥或任意环境变量名；密钥不进入报告、记录或命令参数。节点 SSH 环境通常不加载交互式 shell 配置，密钥须在实际执行进程里可用。未配置时该项直接显示跳过，完整体检仍继续。

## 高级测量位置

默认一键体检已选择节点侧网络与真实代理入口。需要研究特定方向时，可只执行网络部分或在操作机测量：

| 命令 | 发起位置 | 用途 |
| --- | --- | --- |
| `mpx node diagnose 1 --network-only` | 节点 | 仅网络体检，不运行健康和入口能力检查 |
| `mpx node diagnose 1 --network-only --from control` | 控制面 | 默认对该节点地址做 DNS、ICMP、路由；无 HTTP 地址则跳过 HTTP |
| `mpx diagnose` | 当前操作机 | 操作机的外部网络测量，测速默认关闭 |
| `mpx diagnose --socks5 socks5h://127.0.0.1:7890 --speed` | 操作机经指定代理 | 测真实客户端路径；代理不可用时不直连回退 |

控制面测量的出口 IP 属于控制面，不能当作目标节点出口。本地 SOCKS 模式全部 HTTP 请求通过指定代理，DNS 交给代理端，原生 ICMP 和路由明确跳过；SOCKS URL 暂不支持凭证。本地结果只输出，不写入控制面的最新报告。

重复 --target 可添加最多六个目标，--target-http、--target-name 与 --target-region 按顺序对应。地区标签由操作者提供。单次时间上限 15 秒、总网络时间上限 170 秒、样本上限五次、测速站上限三个。本地 --ip-quality-key-env 和 --ip-reputation-key-env 可指定密钥所在环境变量，详细参数见命令 --help。
