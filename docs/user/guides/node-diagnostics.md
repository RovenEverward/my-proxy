# 节点一键体检

一条命令汇总节点健康、配置漂移、全部获授权的真实代理入口，以及官方 Go ECS 融合怪的节点测评。默认使用固定版本 v0.2.12，测速开启，CPU、内存与磁盘压测关闭。

```bash
# 一键检查一个节点
mpx node diagnose 1

# 逐个检查全部节点，某个节点失败仍继续其余节点
mpx node diagnose --all

# 查看最新报告，不重新消耗流量
mpx node diagnostics 1

# 结构化输出
mpx node diagnose --all -o json
```

## 执行体检

完整体检先检查 SSH、核心服务、配置漂移和证书，再运行节点侧融合怪测评。随后逐个通过已配置的真实代理入口检测出口 IP、YouTube 连通性与 Netflix 页面证据。入口使用已有的活跃且获授权的用户。无可用用户、动态专属域名、排空或入口异常都会写入报告。

融合怪测评包含系统基础信息、流媒体、IP 安全数据、邮件端口、线路、延迟、NAT 和测速等上游模块。它测量节点自身的网络；代理入口结果单独列出。测速开启时，mpx 先运行融合怪的非测速模块并保存结果，再使用同一总预算的剩余时间运行融合怪测速，最后合并成一份报告。后阶段失败或超时会保留前阶段证据。`adapter_stages` 记录各阶段时间、状态和错误；各模块是否成功以报告为准，缺少结果不会补成成功。

```bash
# 保留完整体检，关闭融合怪测速
mpx node diagnose 1 --speed=false

# 显式启用 CPU、内存和磁盘测试
mpx node diagnose 1 --hardware

# 将融合怪执行上限改为 10 分钟
mpx node diagnose 1 --fusion-timeout 10m

# 使用原有的轻量完整体检
mpx node diagnose 1 --engine light
```

融合怪默认最多执行 15 分钟，`--fusion-timeout` 接受 60 秒至 30 分钟的整秒时长。完整流程另留 3 分钟给健康和入口检查；默认流程预算为 18 分钟。服务端与 CLI 再分别留 30 秒和 45 秒用于返回报告。`--all` 对每个节点分别应用预算，取消后停止后续节点。

**融合怪测速按时间限制，不提供 32 MiB 流量硬上限。** 上游测速可能消耗较多上传和下载流量。`--speed=false` 关闭测速及国内三网 NT3 扩展，只运行一次融合怪。测速开启时，首阶段保留国内省份延迟测试，后阶段只合入 `speed.registry` 的测速数据；上游后阶段仍可能重复少量 IP 与 NAT 查询，其结果不会覆盖首阶段。硬件压测默认关闭，避免在忙碌的代理节点增加 CPU、内存和磁盘负载。

首次执行时，控制面下载并缓存经过 SHA-256 校验的官方 ZIP，将独立测评程序安装到节点。节点不需要连接 GitHub。体检不更新系统软件包，不安装常驻代理，也不重启 Xray。

服务端一次只运行一个体检；同节点同测量位置至少间隔一分钟。每节点只保存 node/control 各一份最新报告，单份最多 256 KiB。取消时尽量保存部分证据。报告保留测量时间与开始时的节点地址，后续编辑地址不会改写旧报告。

## 查看结果与隐私

报告分别呈现健康、漂移、入口能力和融合怪结果。融合怪保留上游文本与真实结构化数据，并显示版本、执行状态和起止时间。超过保存预算时优先精简目录和展开证据，保留服务结果、地区、风险来源、测速与回程统计；省略字段、数量和大小列在 `payload_omissions` 中。异常超大载荷会明确标注整体省略。部分成功、失败、超时、取消及缺失的结构化结果会明确标注。退出码为 0 也不代表全部模块完成。

一键报告区分本次入口观察与需要两次一致观察的稳定能力状态。不会为了等待稳定状态自动重复测试。Netflix 缺少可靠证据时保持未知；YouTube 成功只说明连通性。原有能力结果仍用于用途订阅筛选，网络测速不会自动剔除候选。

- 路由结果只说明所测方向，不能证明回程。中间路由器限制回复时，高丢包或星号不代表转发丢包。
- ASN 表示 IP 注册归属，不能当作完整 BGP AS 路径或据此判断线路等级。
- IPv4、IPv6 分别记录实际出口；一个地址的地理位置或信誉不能推广到另一地址。
- GeoIP 不保证物理机房位置；供应商信誉数据不代表安全保证。

融合怪固定关闭报告上传，并启用上游隐私模式以关闭其统计信标。隐私模式仍会请求外部 IP、流媒体和其他测评服务；它不等于离线测量。上游结构化报告的 `text` 可为空，但前面的终端文本仍可能包含真实 IP。分享报告前检查文本和 JSON 中的地址及主机信息。

## 选择轻量模式或测量位置

需要固定 HTTP 流量预算时，使用 `--engine light`。它保留健康、漂移和真实入口检查，用原有的有界网络测量替代融合怪。需要只检查网络时，使用 `--network-only`。`--from control` 默认选择 light；融合怪只支持 node 位置。

| 命令 | 发起位置 | 用途 |
| --- | --- | --- |
| `mpx node diagnose 1 --engine light` | 节点 | 原有完整体检，测速默认开启 |
| `mpx node diagnose 1 --network-only` | 节点 | 仅有界网络体检，测速默认关闭 |
| `mpx node diagnose 1 --from control` | 控制面 | 健康和入口检查，加控制面侧轻量网络测量 |
| `mpx node diagnose 1 --network-only --from control` | 控制面 | 仅对节点地址做 DNS、ICMP、路由；无 HTTP 地址则跳过 HTTP |
| `mpx diagnose` | 当前操作机 | 本地有界网络测量，测速默认关闭 |
| `mpx diagnose --socks5 socks5h://127.0.0.1:7890 --speed` | 操作机经指定代理 | 测真实客户端路径；代理不可用时不直连回退 |

控制面测量的出口 IP 属于控制面，不能当作节点出口。本地 SOCKS 模式的全部 HTTP 请求通过指定代理，DNS 交给代理端，原生 ICMP 和路由明确跳过。SOCKS URL 暂不支持凭证。本地结果只输出，不保存到控制面。

轻量网络测量默认 HTTP 应用数据预算为 32 MiB，总时限 120 秒，最大 170 秒。HTTP、DNS 和 ping 单次默认 5 秒，最大 15 秒；延迟默认采样 3 次，最多 5 次。每个目标的 mtr 与 traceroute 回退共享最多 20 秒。轻量完整流程最多 6 分钟；仅网络模式的 API 预算为 3 分钟。

```bash
# 限制轻量网络测量的流量和时间
mpx node diagnose 1 --engine light --max-bytes 16777216 --speed-bytes 1048576 --timeout 120s
```

轻量测速默认使用 Cloudflare anycast 接口与 LibreSpeed 官方注册表中的 Clouvider 洛杉矶站，每站每方向请求 1 MiB。Clouvider 下载按 1 MiB 块向上取整，按实际请求量预留预算。上传成功表示客户端发送完成且站点返回成功，该站不提供服务端接收字节回执。小样本包含握手和请求耗时，不能代表长期最大带宽。

32 MiB 只限制轻量网络测量的 HTTP 应用数据，不包含 HTTP 头、TLS、TCP 重传或单独的代理入口探测。入口每次正文最多 8 MiB，每入口最多四次请求，最长 65 秒。`--timeout`、`--max-bytes`、目标和供应商配置仅适用于轻量或仅网络模式；默认融合怪会拒绝这些参数。

轻量模式使用已安装的 curl、ping、mtr 或 traceroute，不自动安装缺失工具。ICMP 延迟为 Echo RTT；HTTP 延迟为 curl time_total，包含连接、TLS 与响应体完成。失败率单独统计，抖动为相邻成功样本差值绝对值的均值，样本不足时保持未知。

轻量 IP 数据无需密钥即可获取出口 IP 和 ipwho.is GeoIP/ASN。执行机器的 `MPX_IPAPI_IS_KEY` 可补充 ipapi.is 标记，`MPX_ABUSEIPDB_KEY` 可补充社区举报置信度。缺少密钥时跳过，缺失字段保持未知。密钥不经远程 API 接收，也不进入报告或命令参数。节点 SSH 环境通常不加载交互式 shell 配置，密钥须在实际进程环境中可用。

重复 `--target` 可添加最多六个目标；`--target-http`、`--target-name` 与 `--target-region` 按顺序对应。测速站最多三个，地区标签由操作者提供。本地 `--ip-quality-key-env` 和 `--ip-reputation-key-env` 可指定密钥所在环境变量。详细参数见命令 `--help`。
