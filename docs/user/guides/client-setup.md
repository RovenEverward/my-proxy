# 客户端订阅导入与使用指南

本文档面向从管理员处获取订阅链接的终端用户，介绍如何将订阅导入常用客户端、如何通过网页版仪表盘管理订阅，以及常见连接问题自检。

---

## 1. 订阅地址与 Web 仪表盘

管理员通常会发给你一条形如 `https://proxy.example.com/sub/<你的Token>` 的订阅链接。

### 在浏览器中打开（查看用量与自助维护）

直接在网页浏览器中粘贴打开这条链接，你将看到私有订阅控制面板：

1. **状态标识**：
   - 绿色 `可用`：账号状态正常。
   - 灰色 `已停用`：已被管理员临时停用。
   - 橙色 `已过期`：服务期限已到。
   - 红色 `已超限`：已用流量超出限额。
2. **用量进度条**：直观展示已用流量、总限额（或不限）及当前计费周期的剩余额度。
3. **到期时间**：显示精确的失效日期与剩余天数。
4. **格式专享链接**：页面底部列出了各个客户端的直接下载地址，支持一键点击复制。
5. **换个订阅地址（自主轮换 Token）**：
   - 如果怀疑订阅链接泄露，可以点击页面右上角的 **「换个订阅地址」** 按钮。
   - **重要**：点击后当前旧地址立即永久失效，浏览器会显示全新的订阅地址。你必须立即将新地址复制并更新到所有客户端中。底层连接密钥保持不变，无需重新配置节点参数。

## 2. 常见客户端导入步骤

推荐直接使用通用订阅地址（`/sub/<Token>`），服务端会根据客户端软件的 User-Agent 自动返回匹配的格式。

### Clash Verge / Clash Nyanpasu / Mihomo Party

1. 打开客户端，进入 **订阅 / 订阅管理 (Profiles)** 页面。
2. 点击 **新建 / 创建 (New Profile)**。
3. 填写配置：
   - **名称 (Name)**：自定义（如：我的节点）。
   - **类型 (Type)**：选择 `Remote` 或 `URL`。
   - **订阅 URL (Subscription URL)**：粘贴通用的 `/sub/<Token>`。
     *若客户端自动识别失败，可显式使用 `/sub/<Token>/clash-meta`*。
4. 点击 **保存并更新 (Save & Download)**。
5. 在「代理 (Proxies)」页面选择节点，开启「系统代理 (System Proxy)」即可开始使用。

### sing-box (图形客户端或移动端)

1. 打开客户端，进入 **Profiles (配置)**。
2. 添加新的 Remote Profile，URL 填写：
   ```
   https://proxy.example.com/sub/<你的Token>/sing-box
   ```
3. 保存并触发更新拉取。

### v2rayN (Windows) / v2rayNG (Android)

1. 打开软件，点击菜单栏 **订阅设置 (Subscription settings)**。
2. 点击 **添加 (Add)**：
   - **备注**：任意填写。
   - **地址 (URL)**：填写 `/sub/<Token>` 或 `/sub/<Token>/base64-links`。
3. 保存后，在主界面点击 **订阅 -> 更新全部订阅 (Update subscriptions)**。
4. 列表中会刷新出全部节点，选中节点并回车（或设为活动服务器）。

### Shadowrocket (小火箭 - iOS)

1. 点击右上角 **「+」** 号添加节点。
2. **类型** 选择 `Subscribe`。
3. **URL** 粘贴 `/sub/<Token>`，备注任意。
4. 点击右上角 **完成**，软件会自动加载所有可用节点。

## 3. 常见问题排查（Troubleshooting）

### Q1: 节点列表里出现名为「账号已停用 / 账号已过期 / 流量已超限」的节点，端口是 1，无法连接？

这是服务端给出的显式占位提示节点：
- **原因**：你的账号已被管理员停用、订阅有效期已过，或总用量已达到配额上限。
- **解决办法**：请在浏览器中打开订阅链接确认具体原因，并联系你的服务提供者办理续期或重置流量。

### Q2: 客户端拉取订阅时提示「订阅不存在」(404)？

- **原因 1**：Token 输入有误，注意不要复制多余的空格。
- **原因 2**：你曾经在浏览器中点击过「换个订阅地址」，导致旧链接已被废弃。
- **解决办法**：请使用轮换后的最新 Token 地址，或联系管理员重新分发。

### Q3: 导入成功但连接节点超时无网络？

1. 检查客户端的本地系统时间是否准确。代理协议（特别是 VMess、REALITY）要求本地时间与标准时间误差在 90 秒以内。
2. 检查是否开启了杀毒软件或第三方网络过滤软件拦截了代理流量。
3. 切换不同的节点重试。如全部节点不可用，请向管理员反映节点健康状态。
