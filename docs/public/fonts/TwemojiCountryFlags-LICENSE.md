# Twemoji Country Flags

TwemojiCountryFlags.woff2 comes from the npm package country-flag-emoji-polyfill 0.1.10
(https://github.com/talkjs/country-flag-emoji-polyfill).

The flag artwork comes from Twemoji (https://github.com/twitter/twemoji),
Copyright 2019 Twitter, Inc and other contributors, licensed under CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/

The font packaging code is Copyright (c) 2022 TalkJS, MIT License.

MPX bundles the font so that country flags (regional-indicator pairs such as 🇯🇵)
render on Windows, which has no color flag glyphs. The font is applied only to
U+1F1E6–U+1F1FF via unicode-range; all other text uses the regular fonts.
